# Commerce domain review

Review each linked YAML and manifest row. Confirm risk, initial facts, expected outcome, valid alternatives, assertions, policy, severity, and mutant. Record exactly one allowed outcome in `review-status.json`: `approved`, `approved_with_correction`, `rejected`, or `needs_subject_matter_clarification`. Leave `pending` when undecided. Corrections to executable facts or assertions require a YAML change and therefore a new executable hash; review notes alone do not.
