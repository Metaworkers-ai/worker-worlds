# Concepts

A **World** is an isolated deterministic state machine. A **Worker** acts only
through exposed tools. A **Scenario** supplies seed, trigger, budgets, assertions,
and policy intent. A **Run** preserves normalized turns, **WorldEvents**, initial
and final snapshots, and resource evidence. An **Assertion** evaluates one fact;
a reusable **Policy** evaluates commerce safety. A **Verdict** is a typed result
with bounded evidence. A **Suite** retains every run and aggregates outcomes. A
**Baseline** is an immutable content-addressed suite. An **outcome signature**
normalizes material behavior, and a **behavioral comparison** gates changes in
those distributions.
